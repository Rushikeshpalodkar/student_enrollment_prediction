📋 How to Use Power BI Files:

  1. Click any button above to download the CSV file
  2. Open Power BI Desktop (free from Microsoft)
  3. Get Data → Text/CSV
  4. Select the downloaded file
  5. Create visualizations using the data

💡 Suggested Visualizations:

  • Bar Charts: Enrollment by major
  • Line Charts: Historical trends over time
  • Pie Charts: Gender distribution
  • Tables: Detailed breakdowns
  • Cards: Key metrics and totals
