# 📊 POWER BI CONNECTION GUIDE

## 🎯 Step-by-Step Instructions

### **Step 1: Download Power BI Desktop (Free)**
1. Go to: https://powerbi.microsoft.com/desktop/
2. Click "Download free"
3. Install Power BI Desktop on your computer

### **Step 2: Download Your Data Files**
1. Go to: **http://localhost:8080/presentation**
2. Click each download button to get your CSV files:
   - 📊 Current Enrollment Data
   - 🎯 Capacity Analysis Data  
   - 📚 Historical Trends Data
   - 🚻 Gender Analysis Data
   - 🏫 School Analysis Data
   - 📅 Yearly Trends Data

### **Step 3: Connect to Power BI Desktop**

#### **For Each CSV File:**
1. **Open Power BI Desktop**
2. **Get Data** → Click "Get Data" button
3. **Select "Text/CSV"** from the list
4. **Browse** to your downloaded CSV file
5. **Click "Load"** (Power BI will preview the data)
6. **Transform Data** if needed (optional)
7. **Close & Apply**

### **Step 4: Create Visualizations**

#### **Recommended Charts for Each Dataset:**

**📊 Current Enrollment:**
- **Bar Chart**: Enrollment by Major
- **Pie Chart**: Program Distribution
- **Cards**: Total Students, Total Programs

**🎯 Capacity Analysis:**
- **Gauge Chart**: Capacity Utilization %
- **Bar Chart**: Over/Under Capacity Programs
- **Table**: Detailed Capacity by Program

**📚 Historical Trends:**
- **Line Chart**: Enrollment Over Time
- **Area Chart**: Growth Trends by Year
- **Stacked Bar**: Year-over-Year Changes

**🚻 Gender Analysis:**
- **Pie Chart**: Overall Gender Distribution
- **Stacked Bar**: Gender by Major
- **Heat Map**: Gender Balance by Program

**🏫 School Analysis:**
- **Tree Map**: Students by School/Department
- **Bar Chart**: School Enrollment Comparison
- **Cards**: Top Performing Schools

**📅 Yearly Trends:**
- **Line Chart**: Multi-Year Trends
- **Waterfall Chart**: Year-over-Year Changes
- **Table**: Yearly Summary Statistics

### **Step 5: Create a Dashboard**
1. **Arrange visuals** on the canvas
2. **Add filters** and slicers for interactivity
3. **Format colors** and themes
4. **Save your report**
5. **Publish** to Power BI service (optional)

## 🎨 **Power BI Tips:**

### **Best Practices:**
- **Use consistent colors** across charts
- **Add titles** to all visuals
- **Include filters** for date ranges, programs, etc.
- **Use cards** for key metrics (total students, averages, etc.)
- **Group related visuals** together

### **Interactive Features:**
- **Cross-filtering**: Click one chart to filter others
- **Drill-down**: Add hierarchy levels (Year → Semester → Month)
- **Slicers**: Add dropdown filters for users
- **Bookmarks**: Save specific views

---

## 🔧 **Troubleshooting:**

**If CSV won't load:**
- Check file isn't corrupted
- Try opening in Excel first
- Ensure file has headers

**If data looks wrong:**
- Use "Transform Data" to clean up
- Check data types (numbers, dates, text)
- Remove empty rows/columns

**Need help with specific charts:**
- Use Power BI's built-in templates
- Check Power BI community forums
- YouTube has great tutorials
